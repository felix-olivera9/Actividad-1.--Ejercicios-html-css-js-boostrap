# Prácticas de Programación Web

Este repositorio contiene una serie de ejercicios prácticos desarrollados para la materia de programación web, abarcando desde la estructura básica con HTML5, estilización avanzada con CSS3 (Flexbox, Grid, variables, diseño responsivo), hasta interactividad dinámica utilizando JavaScript puro (DOM, validaciones y cálculos matemáticos en tiempo real).

## Contenido del Repositorio
- **HTML Estructural**: Páginas con elementos semánticos, tablas complejas y formularios.
- **CSS3**: Diseños personalizados, hojas de estilos externas y adaptabilidad visual.
- **JavaScript**: Scripts orientados al manejo de eventos, validación de datos de entrada y manipulación lógica sin recarga de página.
